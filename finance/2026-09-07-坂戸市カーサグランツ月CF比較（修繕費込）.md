## 修繕予備費の実務

### 積立と実績

```
例：10年間の積立と実績

┌─────────────────────────────────┐
│ 月¥12,000 × 120ヶ月 = ¥1,440,000 │
│ （10年間の積立総額）              │
└─────────────────────────────────┘
         │
         ├─ 実績修繕
         │  ├─ 5年目：外壁塗装 ¥450,000
         │  └─ 8年目：屋根修繕 ¥150,000
         │  = 合計 ¥600,000
         │
         └─ 残積立：¥840,000
            （10年後に繰越、または11年目以降で大規模修繕）
```

### CFとの関係

- **修繕が少ない年**：月CF ¥62,400が実際に手取りになる
- **修繕が発生した年**：この¥12,000/月の積立から充当
- **修繕を先送りした場合**：積立金が増える（次期修繕に備える）

## 購入判断：どのシナリオを選ぶ？

### 1棟目としての最適解：サブリース継続

```
✅ 理由
• 月CF ¥62,400 は確定（銀行審査に強い）
• 10年間のリスク回避（空室・滞納なし）
• 運営手間がない（時間を次の物件開拓に使える）
• 修繕も松堀が対応（松堀の手数料に含まれる）
• 出口選択肢を残せる（10年後に直管理へ転換可能）

❌ 欠点
• 月CF が限定的（¥62,400）
• 松堀に依存（品質・対応に懸念の余地）
• 10年後の更新条件が未定
```

### 10年後の追加手取りを狙う場合：サブリース解除

```
✅ 利点
• 月CF ¥77,400 ～ ¥96,400（+¥15,000 ～ +¥34,000）
• 10年間で +¥1.8M ～ +¥4.08M の追加手取り
• 長期保有で資産形成を加速

❌ 欠点
• 空室・滞納リスクが直撃
• 運営手間（月50〜100時間）
• 修繕トラブル対応を自分で対応
• CF が月変動（稼働率次第）
```


## 推奨：段階的アプローチ

### 案：「10年サブリース → 11年目から直管理へ」

```
【0〜10年目：サブリース】
• 月CF ¥62,400（確定）
• 手間なし（時間を物件開拓に）
• 融資審査に有利（CF安定実績）
• 累計CF ¥7,488,000

【11年目以降：直管理へ転換】
• 月CF ¥96,400（管理費込）
• 時間投下（月50〜100時間）
• 残債¥13,000,000〜¥15,000,000
• 新たな融資の必要性は低い（既存債務で営業）

【20年後：ローン完済】
• 残ローンゼロ
• 月CF ¥96,400がそのまま手取り
• 長期保有で資産形成完了
```

このアプローチなら、**1棟目の「安定」と長期の「CF最大化」の両立** ができます。
