## LTV（融資比率）分析

### 購入価格 vs 積算評価

```
購入価格        ¥3,650万
積算評価        ¥2,652万
──────────────────
乖離            ¥998万（購入価格が27.5%高い）
```

### 融資パターン別 LTV

**パターン①（融資¥30,800,000・19年・2.9%）**
```
LTV = ¥30,800万 ÷ ¥2,652万 = 116.1%

判定：❌ 積算評価を超える
     → 銀行は「積算評価額までの融資」が原則
     → 実際には ¥2,652万 × 80% = ¥2,122万 程度が限度か
```

**パターン②（融資¥29,500,000・25年・3.0%）**
```
LTV = ¥29,500万 ÷ ¥2,652万 = 111.1%

判定：❌ 積算評価を超える
     → 同じく融資額が高い
```

**パターン③（融資¥36,500,000・35年・4.275%）**
```
LTV = ¥36,500万 ÷ ¥2,652万 = 137.6%

判定：❌❌ 極めて高い
     → フルローンは銀行の基準では不可能
```

## 🚨 重大な懸念：融資が組めるか不透明

### 問題点

```
購入価格 ¥3,650万
積算評価 ¥2,652万

購入価格が積算評価を27.5%上回っている

銀行の融資実務ルール：
• 融資額は「積算評価の70%～80%」が限度
• 残りは自己資金で補充
```

### 実際に組める融資額の推定

```
積算評価 ¥2,652万

× 80%（やや有利な場合）= ¥2,122万
× 70%（標準的）        = ¥1,856万
× 60%（厳しい場合）    = ¥1,591万

典型的な融資額（70%想定）：¥1,856万
```

### 必要な自己資金（購入価格¥3,650万の場合）

```
購入価格         ¥3,650万
融資可能額（70%） −¥1,856万
─────────────────────
必要自己資金      ¥1,794万

想定していた自己資金（パターン①）：¥570万
実際に必要：¥1,794万
ギャップ：¥1,224万不足
```

## 💡 解決策

### オプションA：売却価格を積算評価に合わせるよう交渉

```
現在の交渉：¥3,650万（積算評価¥2,652万に対して27.5%高）

交渉ターゲット：¥2,800万～¥2,900万
（積算評価と相場のバランスポイント）

利点：
• 銀行融資が組みやすくなる
• 自己資金の負担が減る
• LTVが適正範囲に収まる
```

### オプションB：現在の購入価格で、自己資金を増やす

```
購入価格：¥3,650万（現在のまま）
融資可能額：¥1,856万（積算評価70%）
必要自己資金：¥1,794万

現実性：△ 
• 自己資金¥1,794万 は投資初期段階では厳しい
• ただし、Shiga Bank が「収益還元評価」で上乗せしてくれる可能性は残る
```

### オプションC：収益還元評価で融資をカバー

```
見沼区の収益還元評価（満室ベース）

年間CF（パターン②）：¥1,770,480
利回り8.5%で逆算：¥1,770,480 ÷ 0.085 = ¥20,829,000

実際の積算評価：¥2,652万
収益還元評価：¥2,083万

銀行の実務：
• 積算評価＋収益還元評価の平均で判定することもある
• 平均評価 = (¥2,652 + ¥2,083) ÷ 2 = ¥2,368万
• この場合、融資可能額 = ¥2,368万 × 80% = ¥1,894万

それでも購入価格¥3,650万には遠い
```

## 最終判定

### 🔴 融資実行性が不透明

```
見沼区の積算評価¥2,652万は、購入価格¥3,650万に対して
著しく低い状態。

通常の銀行融資では：
• 融資額は積算評価の70%～80%が限度
• ¥2,652万 × 70% = ¥1,856万 が現実的な融資上限
• 購入価格¥3,650万を実行するには自己資金¥1,794万必要

これは「融資が組みにくい物件」を示唆している。
```
