## 所沢の投資判断

### 🟡 利点

1. **築浅（築10年）** → 修繕リスク低い
2. **スケール感（8戸）** → ポートフォリオ拡張に◎
3. **駅近（徒歩10分）** → 賃貸需要が安定
4. **価格交渉の余地** → ¥7,000万の実現性あり

### 🔴 懸念点

1. **月CFが小さすぎる**
   - サブリース¥380,000なら月¥37,500
   - 坂戸の¥122,900より31%
   - 規模の割に利益が薄い

2. **直管理転換後もCFが改善しない**
   - 直管理でも月¥32,740（90%稼働想定）
   - ほぼブレークイーブン状態
   - 修繕が出ると赤字に

3. **融資難度が高い**
   - 木造・築10年で滋賀銀行OK？
   - 金利がどうなるか不透明

4. **サブリース条件が未確定**
   - 保証額が¥360,000なら月CF¥17,500（ほぼアウト）
   - 保証額が¥400,000なら月CF¥57,500（対応可能）
   - この振幅が大きすぎる

## 最終判定

### 投資判断

```
🟡 「情報待ち」が「見送り推奨」に転換の可能性
```

**理由**：
- CF が小さすぎて、規模メリットが出ない
- 坂戸を¥3,980万で1棟買う方が、¥7,000万1棟買うより効率がいい
- 高崎の¥4,900万でも所沢より月CFが高い（¥190,700 vs ¥37,500）

**ただし、サブリース条件次第**：
- サブリース¥400,000以上なら月¥57,500で対応可能
- その場合は「検討の余地あり」に上がる
