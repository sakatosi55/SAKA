# 坂戸 vs 高崎 —— 築年数・管理方式による実質リスク比較

**重要な違い**:
- **坂戸**: 築11年 + サブリース満室保証 = 空室リスク**ゼロ**
- **高崎**: 築30年 + 直管理 = 空室が**直接CFに影響**

---

## 基本特性の比較

| 項目 | 坂戸 | 高崎 |
|------|------|------|
| **築年数** | 築11年 | 築30年 |
| **構造** | 軽量鉄骨造 | 軽量鉄骨造 |
| **管理方式** | サブリース（松堀不動産） | 直管理 |
| **保証内容** | ¥282,000/月 保証<br>空室でも保証 | 実際の家賃収入のみ<br>空室は直撃 |
| **大規模修繕** | 不明（要確認） | 5年前に完了済み |
| **修繕リスク** | 短中期で修繕の可能性 | 当面修繕負担軽い（15年は大丈夫） |

```

月CF  ¥105,400 → ¥6,400（−¥99,000）
危機的状況
 ↓
【結論】
満室維持が死活問題
築30年で退去・建替えのリスク増加
```

## 満室維持の現実性

### 坂戸：満室**保証**（松堀が保証）

```
入居 = オーナーの責任 0
退去 = 松堀の責任（ただし¥282,000の保証範囲内）

つまり：
• 空室が出ても松堀が埋める
• または¥282,000の保証で手当て
• オーナーは何もしなくてよい
```

### 高崎：満室**維持**が必須（オーナー責任）

```
現況：8戸中7戸入居
退去予定：201号室（5月）

課題：
• 再募集期間が長いと月CF に直撃
• 築30年で「古い」イメージ
• ユーザーが現地で「5.2万で募集」を確認済み
  = 相場は厳しい（供給過剰の可能性）
• 次の退去が来たらすぐに埋まるか？

リスク：
• 2戸空くと月CF ¥6,400（危機）
• 建替え・取壊しのリスク（築30年）
  = 実質償却年数 34年だが、
    実務ではもっと早い可能性
```

## 結論：投資判断の修正

### 坂戸：最優先ターゲット ✅

```
理由：
1. サブリース満室保証で空室リスク ZERO
   → 金利がいくらでも対応可能（2.0%〜4.0%）
   
2. 築11年で修繕リスク中程度
   → 向こう10年は修繕コスト低い可能性
   
3. 経営難度が極めて低い
   → 「大家業」が初心者向き
   
4. 月CF ¥147,350（金利2.0%）は堅い
   → サブリース10年間は確定

【判定】
金利2.0%：✅✅ 最優先ゴー（完璧）
金利2.5%：✅✅ ゴー（十分）
金利3.0%：✅ ゴー（許容）
金利4.0%：✅ ゴー（修繕注視）
```

### 高崎：条件付きでゴー ⚠️

```
理由：
1. 満室維持がカギ
   → オーナーの経営手腕に依存
   
2. 5年前の大規模修繕済みはプラス
   → 今後15年は修繕コスト低い
   
3. 築30年で退去・建替えリスク増加
   → 10年後の出口戦略が重要
   
4. 月CF（金利4.0%）¥105,400 は限定的
   → 空室1戸で一気に圧迫される

【判定】
金利2.0%：✅✅ ゴー（安全）
金利2.5%：✅ ゴー（基準・満室維持が前提）
金利3.0%：✅ ゴー（注意が必要）
金利4.0%：⚠️ 許容範囲（慎重に）

条件：
• 現地で賃料相場・退去率を確認
• レントロール取得で実賃料の稼働性確認
• 修繕計画書の取得（いつまで修繕不要か）
• 満室維持できる管理体制の構築
```
