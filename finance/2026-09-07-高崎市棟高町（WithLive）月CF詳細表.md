## 損益分岐点：何戸入居でCFゼロになるか

### 金利2.5%の場合

```
月返済            ¥227,200
固定資産税        ¥18,000
火災保険          ¥5,600
修繕費            ¥15,000
─────────────────
固定月支出        ¥265,800

月CF = 0 になる月賃料 = ¥265,800
1戸当たり平均賃料 = ¥49,500

必要戸数 = ¥265,800 ÷ ¥49,500 ≈ 5.36戸

つまり 5.4戸（実質5〜6戸）が入居すれば CF ゼロ
稼働率 = 5.4戸 ÷ 8戸 = **67.5%**
```

### 金利4.0%の場合

```
月返済            ¥253,000
固定資産税        ¥18,000
火災保険          ¥5,600
修繕費            ¥15,000
─────────────────
固定月支出        ¥291,600

月CF = 0 になる月賃料 = ¥291,600
1戸当たり平均賃料 = ¥49,500

必要戸数 = ¥291,600 ÷ ¥49,500 ≈ 5.89戸

つまり 5.9戸（実質6戸）が入居すれば CF ゼロ
稼働率 = 5.9戸 ÷ 8戸 = **73.75%**
```
