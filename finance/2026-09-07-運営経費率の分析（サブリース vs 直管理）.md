**作成日**: 2026-09-07  
**目的**: 同じ物件について、運営経費率がいかに変わり、月次CFにどう影響するかを明確化する

---

## 実際の租賃収入の構図

### 現状（満室・6戸稼働）

```
┌─────────────────────────────────┐
│   入居者から徴収（月額）         │
│     ¥396,000                    │
│  （¥66,000/戸 × 6戸）            │
└─────────────────────────────────┘
            │
```

## 3つのシナリオ

### シナリオ1：サブリース管理（松堀不動産） — 継続保有

```
┌─────────────────────────────┐
│ 月間租賃収入（実績）         │
│   ¥396,000                 │
└─────────────────────────────┘
        │

        │  └─ 対象に含まれるもの：
        │    • 入居者対応・苦情処理
        │    • 賃料回収・滞納対応
        │    • 日常メンテナンス（壁穴補修・設備故障等）
        │    • 空室広告・内覧対応
        │    • 退去時原状回復手配
        │
        └─ オーナーが受け取る ¥282,000
           └─ 保証なので、以降の空室状況関係なし
              （10年間確定）

┌─────────────────────────────┐
│ サブリース下のオーナー支出   │
├─────────────────────────────┤
│ • 固定資産税      −¥TBD     │
│ • 火災保険        −¥5,600   │
│ • ローン返済      −¥？      │
│ • 大規模修繕積立  −¥？      │
│  （屋根・外壁・給水管）      │

        │
        └─ 月CF = ¥282,000 - 上記支出

【利点】
✅ 月CF が確定している（10年間）

✅ 空室のリスクがない
✅ 赤字にならない（¥282,000は確定）

【欠点】
❌ フルの月¥396,000は得られない
❌ 10年後の更新条件が未定
❌ 管理会社に依存（品質・対応の懸念）
```

## ポイント整理

### 1. **運営経費率の本質**

| 管理形態 | 月額手数料 | 率（月租賃ベース） | 何が含まれるか |
|--------|---------|-----------|----------|
| サブリース（松堀） | ¥114,000 | **28.8%** | 入居者対応・修繕手配・回収 **すべて** |
| 外部管理会社 | ¥30,000〜40,000 | **7.5〜10%** | 入居者対応・修繕手配・回収のみ |
| 自管理 | ¥0 | **0%** | 手数料なし。時間と手間で対応 |

**一見するとサブリース（28.8%）は高いが、これは「確定性」と「時間削減」の対価。**

## 結論：どのシナリオが最適か

### 選択基準

**シナリオ1（サブリース）を選ぶべき条件**：
- 1棟目で「堅い」CF が必要
- 時間に余裕がない（会社員・忙しい）
- 空室リスク・トラブル対応を避けたい
- 10年後に売却予定
- **短期CFの確実性を重視**

**シナリオ2（自管理）を選ぶべき条件**：
- 長期保有目的（20年以上）
- 時間的余裕がある
- 入居者対応・修繕管理に自信がある
- 月CF を最大化したい
- **長期資産形成を重視**

**シナリオ3（外部管理）を選ぶべき条件**：
- CF と手間のバランスを重視
- 時間は限定的だが完全にはフリーでない
- 修繕・トラブル対応は委託したい
- 空室リスクには耐性がある
- **実務的なバランス型**

## 最後に：運営経費の再定義

**本来「運営経費」とは何か**：

```
                 ┌─────────────────────────────┐
                 │ オーナーが最終的に負担する  │
                 │    時間 ＋ 金銭 の合計      │
                 └─────────────────────────────┘
                            │
                    ┌───────┴───────┐
                    │               │
                【金銭】        【時間・手間】
              交通費・税理士  入居者対応・修繕手配
              修繕費・広告費  督促・内覧対応
```

サブリースは「時間を金銭で買う」戦略であり、28.8%という数字は決して高くない。その代わり、**10年間の CF 安定性と時間削減を得ている**のだ。
