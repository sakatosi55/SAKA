## 金利4.0%での購入判断

### 坂戸：見送り推奨 ❌

```
理由：
1. 月CF ¥79,350 は限定的
   • 修繕が重なると赤字の可能性
   • 空室が出たら危機的状況
   
2. 出口戦略が限定的
   • 10年後に土地値売却は赤字のリスク
   • 利回り売却に依存する必要あり

3. 1棟目としてのリスク
   • CF に余裕がないため、予期しない修繕で運営困難
   • 次の融資枠を考えると危険

4. 金利2.0%なら月CF ¥147,350で「圧倒的推奨」だが、
   金利4.0%で¥79,350では差が大きすぎる

推奨：金利2.0%での融資成功を目指す。
     4.0%なら1棟目は見送り、
     金利が下がるまで待つ方が賢明
```

### 高崎：許容範囲だが慎重に ⚠️

```
理由：
1. 月CF ¥105,400 は許容可能
   • 修繕リスクに対応可能な余裕あり
   • 空室1戸なら月CF ¥54,900（限定的だがプラス）

2. 出口戦略が安全
   • 土地値売却でも黒字（¥2.19M）
   • 利回り売却なら十分な手取り

3. 融資額¥49Mのメリット
   • 資産規模として次への融資評価が向上
   • 規模拡大戦略としての位置づけ

4. ただし以下に注意
   • 修繕積立¥15,000/月で足りるか監視必須
   • 大規模修繕時期（15〜20年目）の金利負担を考慮
   • 満室維持が必須（1戸の空室で月CF が半減）

推奨：金利2.5%が最適。
     金利4.0%なら、十分な現金準備（¥2M以上）の上で進める。
     融資額¥49Mの規模メリットが、
     金利上昇のデメリットを補う。
```
