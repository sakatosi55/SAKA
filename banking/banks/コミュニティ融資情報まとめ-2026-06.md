# コミュニティ融資情報まとめ（2026年6月）

> 不動産投資家コミュニティでの会話から、融資・資本金に関する実務情報を整理。渋沢栄一の参考資料。

## バックファイナンス（複数金融機関からの資金調達）

### 基本的な進め方
1. 本体融資元（メインバンク）に知られない形で進めるのが基本
   - 「全国一括対応で担当者を知らない」等で本体側からの照会をかわす例あり（個別事案、支店・担当者により対応は分かれる）
2. 資金使途を書面で整理してから追加の金融機関に相談する
3. 「融資を受けてもなお収支が回る」ことを示す事業計画書・CF表を用意する
4. 可否は金融機関だけでなく**担当者個人の裁量**に左右されることが多い（「融資は全て個別事案」）

### 用語の整理
- **協調融資**：複数の金融機関が協力して同一物件に融資すること（表向きには好まれない言い方）
- **バックファイナンス**：本融資とは別に、頭金・諸費用部分を別の金融機関から調達すること

### 滋賀銀行「ジャストサポート」
- 本体の物件融資とは別に、諸費用分を融資してもらう手法。コミュニティ内でよく使われている
- 自己資金温存に直結する手法 → [[レオパレスウエノ購入検討]] の920万円現金（頭金520万＋諸経費400万）の一部をカバーできる可能性あり

## 各金融機関の情報

### 関西みらい銀行（2026年6月頭・直申込み時点の金利）
| 融資額 | 金利 |
|--------|------|
| 1,000万〜3,000万円 | 4.55% |
| 3,000万〜5,000万円 | 3.55% |
| 5,000万〜8,000万円 | 2.65% |
| 8,000万〜1億円 | 2.55% |

- サラリーマン向けアパートローン（セゾン保証、物件評価重視）。法人プロパー融資ではない
- 経験者の結論：「5,000万以下→インベースor提携業者経由、5,000万以上→関西みらい直」

### L&F（エルアンドエフ）の融資方針（池袋支店の例）
- 8割融資が基本。総借入5,000万以下・店部決裁の場合、9割まで伸びることがある
- 決裁ライン：5,000万円まで店部決裁／5,000万〜1億円は本部決裁／1億円以上は社長決裁（社長決裁になると外部評価が入り厳しめ、6割融資が多い）
- 融資期間は最長30年。CFを良くするため築年数によらずなるべく30年で審査に出す
- 重視する3点：①物件評価　②CF（他物件・本人属性含む）　③購入動機（不動産屋の言いなりでないか）※③は特に厳しく見られる
- 融資エリア：首都圏（共担があれば北関東も）・仙台・広島・大阪・福岡（北海道・沖縄は不可）
- CIC（個人信用情報）は事前審査時に1回のみ参照、決済時は見ない
- 旧耐震・再建築不可・調整区域（再建築OK）でも対応可
- **対応不可の物件**：シェアハウス、民泊、老人ホーム、生活保護ビジネスが絡む物件
- **レオパレス物件**：界壁施工不備問題の対象物件はNG。**「対象外」証明書があり、支店権限内の物件であれば対応可能**（表向きには「やっていない」と言っている）。イエローゾーンは対応、レッドゾーンは厳しめ
  - → レオパレスウエノは「界壁施工不備について【対象外】」の通知書を保有済み。次にレオパレス系物件を検討する際、L&Fが選択肢になり得る
- 事前審査は営業担当者の判断次第で結果が大きく変わる。プロフィールシートは常に最新化しておくこと
- 共担評価：共担物件の評価額が掛け目を入れて積算に加算される。共担価値以上にはならない
- 積算と収益還元のうち低い方を採用し、そこに掛け目
- 実勢価格ベースで周辺の坪単価より安ければ評価が伸びやすい（耐用年数切れの物件は土地の売値ベースで評価）

### 日本政策金融公庫（公庫）
- 個人・法人どちらにも対応
- 融資上限の目安：**資本金の概ね2倍程度**（公式ルールではなく実務上の感覚値。事業計画・CF・代表者属性等との総合判断）
- 別の融資（例：L&F）の存在を確認しようとする傾向がある。バックファイナンスを進める際は、本融資の存在確認への対応を事前に想定しておく

## 資本金の増資手法（法人で2棟目以降を買う場合に有効）

### 方法①：DES（Debt Equity Swap）
- 現預金（資産側）を直接資本金に組み替える
- **税理士による「確かに移せる現預金がある」という証明書が必要**（やや手続きが煩雑）

### 方法②：役員借入を経由する増資（より簡便）
1. 役員個人の現預金を法人へ「役員借入」として入金（通帳コピーで実在を証明）
2. その入金分を資本金に組み入れ、増資完了（法務局への登記が必要）
3. 増資後、残っている現預金を役員へ返済（役員借入の返済）

- **注意点**：期末までに法務局での増資登記が完了するリードタイムに余裕を持つこと（書類不備で差し戻されると間に合わない）
- 法人の現預金が元々ゼロの状態で「役員借入→資本金→個人に返す」を回すには、返済原資となる現預金が法人に実在することが前提（架空の数字遊びはできない）

## 坂上さんの状況への接続

- レオパレスウエノは**個人**で購入予定
- 2棟目以降は**法人**で購入する方針
- 公庫の「資本金の2倍まで」目安を踏まえると、**法人設立時の資本金額が2棟目の融資上限に直結する**
- 2棟目の想定物件規模・必要融資額が決まれば、逆算して資本金額を設定すべき
- レオパレスウエノの「界壁施工不備【対象外】」証明書は、将来別のレオパレス系物件をL&Fで検討する際の実績として使える可能性あり
