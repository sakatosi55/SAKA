## 🚨 重大な懸念点

### 1. **築37年は「限界」に達している**

```
法定耐用年数（RC造）：47年
築37年時点の残年数：10年のみ

問題：
• 融資銀行が「あと10年で更新不能」と判断する可能性
• 新規融資がいくらで組めるか不透明
• 築古化に伴う修繕コスト激増の可能性
```

### 2. **修繕リスクが極めて高い**

```
築37年で想定される修繕：
• 外壁塗装（大規模）：¥500万～¥1,000万
• 給水管更新：¥300万～¥500万
• 屋上防水：¥200万～¥400万
• サッシ交換：¥100万～¥200万
• 内装更新（必要に応じ）：¥300万～¥500万

累計修繕：¥1,400万～¥2,600万の可能性

修繕予備費¥25,000/月 = 年¥300,000
→ 5年で¥1,500万の積立が必要だが、1年では不足
```

### 3. **2戸空室中（本当に埋まるか）**

```
行田駅は地方駅
賃貸需要が限定的
築37年のRC造で、なぜ2戸が空いているのか？
→ 市場需要が弱まっている可能性
```

### 4. **10年後の出口戦略が不透明**

```
築37年 + 10年 = 築47年（耐用年数到達）
その時点での売却・建替え・取壊しの判断が必須
→ 大きな費用がかかる可能性
```
