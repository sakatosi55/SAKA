- [ ] 前橋市西片貝エリア賃料相場・競合空室率
- [ ] 積算評価概算
- [ ] サブリース解除後の入居率見込み
- [x] 解除条件：違約金なし・解除後6ヶ月はサブリース料支払いあり
- [x] 建物メンテ費用（月42,821円）は解除後なし → 修繕積立に切替
- [x] 現在の入居戸数 → 売主からの正式開示は決済1ヶ月前だが、**オーナー現地確認（2026-06-16）：賃貸サイト等で3〜4室が募集中**。12戸中8〜9戸が稼働中の可能性（推定・非公式情報のため正式開示を待って要確認）
- [ ] 解除後の管理会社選定 → **決済2〜3ヶ月前にアポ・選定開始**
- [x] **空室の部屋はエアコンが撤去される**（レオパレス退去時の標準仕様）→ 再入居前にエアコン新設コストが発生
- [ ] **2階は床がカーペット仕様（1階はフローリングと推定）** → 仲介に確認したが理由不明。**防音目的の可能性あり**（界壁問題の経緯を踏まえると、上階の足音対策で意図的にカーペットにしている可能性）
  → 安易にフローリング化すると1階への音漏れクレームのリスクがあるため、**張替えは保留。空室発生時に現地で再判断**

## 客付けスケジュール（重要：2月から募集可能）

> **解除後6ヶ月のサブリース料受給期間が終わるタイミングが2月頃 → 日本の賃貸最需要期（1〜3月）に合致する好条件**

| 時期 | アクション |
|------|-----------|
| 決済後〜11月 | サブリース料を受け取りながら管理会社の選定を開始（従来の「決済2〜3ヶ月前」より前倒し） |
| **11〜12月** | 管理会社を正式決定。客付け条件（賃料・写真・募集サイト掲載）を整える |
| **1月中** | リフォーム・エアコン新設など、空室を「貸せる状態」に完了させる |
| **2〜3月（最需要期）** | 全空想定でも募集開始 → 新生活シーズン需要を最大限取り込む |
| 4月以降 | 閑散期に入る前に大半の成約を目指す |

- 2〜3月の最需要期に間に合わなければ、次の好機は翌年の同時期まで持ち越しになるため、**1月中の準備完了が必須**
