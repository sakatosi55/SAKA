## 初期評価

### 🟢 利点

1. **価格交渉の余地が大きい**
   - 表示¥7,830万 → ¥7,000万の可能性
   - 利回り改善に直結

2. **築浅（築10年）**
   - 坂戸と同レベル
   - 修繕リスク低い
   - 融資銀行評価も良好

3. **戸数が多い（8戸）**
   - 坂戸の6戸より多い
   - 規模感が出る

4. **駅が近い（徒歩10分）**
   - 清瀬の20分より好立地
   - 賃貸需要が安定

5. **サブリース→直管理への転換戦略**
   - 利回り6.5% → 8.5%へ上昇
   - 段階的なリスク低減
   - ポートフォリオ多様化に最適

### 🟡 懸念点

1. **価格が高い**
   - 坂戸¥3,980万の1.76倍
   - 高崎¥4,900万より¥2,100万高い
   - スケール感の割に割高感

2. **木造構造**
   - 清瀬と同じリスク
   - 融資銀行の評価が厳しい可能性
   - 耐用年数22年を意識した返済期間設定が必須

3. **現在1戸空室**
   - 87.5%稼働
   - 募集が長引くとCF圧迫

4. **サブリース条件が未確認**
   - 保証月額はいくら？
   - 解除のしやすさ（違約金など）

5. **融資可能性が不透明**
   - 木造・築10年で滋賀銀行OK？
   - 最長29年行ける？

## 融資シミュレーション（仮・要確認）

### 想定条件

```
購入価格：¥7,000万（交渉後）
自己資金：¥1,000万（推定）
融資額：¥6,000万
融資期間：29年
金利：2.5%（坂戸と同水準と仮定）
```

### 月返済額の試算

```
融資額¥6,000万、29年、金利2.5%

月返済額 = 6,000万 × [0.001667 × (1.001667)^348] / [(1.001667)^348 - 1]
        ≈ ¥299,500/月
```

### 月CF試算（直管理・サブリース解除後）

```
【サブリース解除後・直管理想定】

月賃料          ¥400,000（50,000/戸 × 8戸）
─────────────────
経費（管理費3%等）−¥12,000
固定資産税      −¥20,000（推定）
火災保険        −¥8,000（推定）
修繕予備費      −¥15,000
ローン返済      −¥299,500

月CF            ¥45,500

年CF            ¥546,000
```

**評価**：月¥45,500では、坂戸（月¥67,700・金利2.5%）より低い。規模の割に割高感。

## 戦略的なポイント

### なぜ所沢は「サブリース→直管理」戦略なのか？

```
坂戸の問題点：
• サブリース保証¥282,000は「上限」
• これ以上の利回り改善ができない
• 築11年で築古化→以後利回り低下リスク

所沢のアドバンテージ：
• 現在サブリース（安定）
• 5年後に解除可能（拡張性）
• 直管理で8.5%へ跳ね上がる
• ポートフォリオの中で「成長株」になる
```

### ポートフォリオ配置戦略

```
🥇 坂戸（安定・堅い）
   サブリース保証¥282,000で月¥67,700
   10年以上安定CF

🥈 所沢（成長・戦略）
   1〜5年：サブリースで月¥?（未確定）
   6年〜：直管理で月¥45,500+
   価値上昇ポテンシャル

🥉 高崎（規模・2棟目）
   2LDK×8戸でスケール感
   月¥130,200（金利2.5%）

🔴 清瀬（見送り推奨）
   高すぎる＆融資難
```
