# エリア分析メモ：埼玉県大里郡寄居町

> 作成日：2026年6月23日　目的：オーナー（トト）の居住地周辺エリアでの物件開拓の初期スクリーニング
>
> **2026-06-23追記**：トト本人の判断により、寄居町は賃料水準が低く（平均5万円前後）規模でカバーしにくいため**対象外**と決定。投資エリアは**埼玉県内**をメインに、**条件が良ければ群馬県も狙う**方針に変更（[owner-profile.md](../../secretary/owner-profile.md)参照）。本メモは比較検討の記録として残す。

---

## 1. 基礎情報

| 項目 | 内容 |
|------|------|
| 所在 | 埼玉県大里郡寄居町（県北西部） |
| 人口 | 約3万人規模の町 |
| 交通 | 寄居駅に**東武東上線（池袋まで約90分）・JR八高線・秩父鉄道**の3路線が乗り入れる交通結節点 |
| エリア特性 | 北関東の物流・工業・商業の要衝。地価が安く土地が豊富。工場用地需要が安定、EC普及で物流業界からの注目も上昇傾向 |

## 2. 賃貸相場

| 指標 | 内容 |
|------|------|
| 大里郡寄居町の賃貸物件平均家賃 | 約5.02万円（登録物件104件・440件規模） |
| 寄居駅周辺の家賃帯 | 概ね3.7万〜6.6万円 |
| 1K相場の目安 | 3万円台〜4万円台が中心、上は6万円台まで（高坂エリアなど沿線他駅の例も含む） |

**評価**：埼玉県内では地価・賃料ともに低め。利回りは出しやすい一方、賃料単価が低いため戸数・規模でカバーする必要がある。

## 3. 投資物件の手応え

- ホームズ不動産投資で寄居駅周辺の収益物件（2億円以下）が検索可能。**利回り15%超の戸建賃貸**も確認できる地域 → 高利回り築古系を探せる土地柄。
- 地元の不動産会社（東和不動産など）が売地・貸家・アパートを扱っており、地場業者とのパイプ構築が有効そう。

## 4. 投資方針との整合性チェック

トトさんの方針（[owner-profile.md](../../secretary/owner-profile.md)）：CF・積算・利回りバランス重視、**築30年以上は対象外**。

- 寄居町は築古高利回り物件が出やすいエリアのため、**築年数フィルターは厳格に運用する必要がある**（医者大家T事例のような築30〜38年再生系は対象外）。
- 居住地（寄居町）に近いというのは、現地確認・管理のしやすさという点で1棟目として大きなアドバンテージ。
- 群馬（高崎・東和銀行高崎支店で打診中）と寄居町は地理的に近接しており、**東和銀行高崎支店の営業エリアと重なる可能性がある**点は要確認（[東和銀行高崎支店.md](../../banking/banks/東和銀行高崎支店.md)）。同じ金融機関で群馬・埼玉北部をカバーできれば、与信枠を1行に集約しやすい。

## 5. 次のアクション（坂本龍馬メモ）

1. 楽待・健美家・SUUMOで寄居町・寄居駅周辺の築30年未満の物件を定期チェック
2. 地場業者（東和不動産など）にコンタクトし、非公開・先出し物件の情報を得る動線を作る
3. 物流・工業需要を背景にした賃貸需要（単身者・ワーカー層）が見込めるかは現地確認で検証
4. 候補物件が出たら `property/deals/YYYY-MM-DD-<案件名>.md` に個別記録
