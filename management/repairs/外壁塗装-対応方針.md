# 外壁塗装 対応方針

作成日: 2026-06-17

---

## 業者選定・見積もり

- 現地確認を必ず実施してもらう
- **3社以上**から相見積もりを取る
- 各社から **塗料の種類** と **工程の説明** を受ける（口頭でなく書面で）

## 見積書チェックポイント

- 工程ごとの内訳が明記されているか
- 使用塗料のメーカー・品番が明記されているか
- 足場・養生・下地処理の費用が別途記載されているか
- 保証年数・保証範囲が明記されているか

## 支払いルール

- **着手前の全額払いは絶対にしない**
- **着工前50% → 完工後50%**
- 領収書・請求書は必ず保管（経費計上のため）

## 工事中の管理

- 作業進捗を**LINE等で随時報告**してもらう（写真付きが望ましい）
- 工程表を事前にもらい、スケジュールを把握しておく
- 可能な限り**現場に顔を出す**（差し入れも有効）
  - 職人さんとの関係構築 → 丁寧な仕事につながる
  - 手抜き防止・工程確認の効果もある

## 確認すべき工程（手抜きされやすいポイント）

1. **高圧洗浄** — 十分に汚れ・旧塗膜を落としているか
   - **雨樋の内側まで洗浄してもらえるか**、契約前に確認する
   - **集水器まわりの落ち葉・詰まり除去**も含めてもらえるか確認する
   - → 基本的に高圧洗浄の料金内でやってもらえるケースが多い。事前に一言確認しておくのが◎
2. **足場** — 揺れによる建物への凹み・傷が発生しやすい
   - **足場解体前に**、凹みや傷がないか全箇所を確認する
   - 補修が必要な箇所は**解体前に直してもらう**ことを契約時に取り決めておく
   - 解体後だと証拠が曖昧になり、逃げられるリスクがある
3. **下地処理（ケレン）** — ひび割れ補修・シーリング打ち替えが丁寧か
3. **塗装回数** — 下塗り・中塗り・上塗りの3回塗りが守られているか（写真で確認）
4. **養生** — 窓・設備が適切に保護されているか
   - **通路への養生が抜けがちなので要確認**（塗料が垂れるケースが多い）
   - 工事中・完工後に通路を目視チェックし、塗料が垂れていたら**必ず指摘して除去してもらう**
   - 養生不足が原因なので、追加費用を請求されても応じない

## 失敗しない10の対策（作成中）

1. **人で選ぶ** — 会社ではなく担当者・職人の質で判断する
2. **誰が施工するかを確認する**
   - 施工する職人と直接話せるのが理想
   - 下請けまでは許容範囲。**孫請けは管理が届かないので避ける**
3. **メーカー保証より施工保証を確認する**
   - 契約前に保証書を見せてもらう
   - 保証範囲の説明を受ける（施工保証 と 塗料保証 の両方）
4. **支払いスケジュール**
   - 契約時10%以内 → 着工時30% → 中間検査時40% → 完工後20%
   - ※オーナー判断で「着工前50% → 完工後50%」に変更してもよい
5. **塗料缶を写真で残す**
   - 品番・ロット番号が写るように撮影
   - 開封後も写真を撮ってもらう（偽物・希釈過多の防止）
6. **工程写真を義務化する**
   - 見えない工程を可視化して手抜きを防止
   - 撮影タイミング：洗浄前 → 洗浄後 → 下塗り → 中塗り → 上塗り → 完成
   - **LINEで都度報告してもらう**ことを契約前に取り決める
7. **一式見積もりを禁止する**
   - 必ず**明細見積もり**を要求する
   - 業者間の比較がしやすくなる
   - 使用塗料名・塗装回数も明記させる
8. **足場業者の保険を確認する**
   - 保険加入は必須（未加入業者は使わない）
   - 足場倒壊・建物損傷時の補償が対象か確認
9. **近隣対応を確認する**
   - 近隣クレームは入居者トラブル・退去につながる
   - 事前に近隣挨拶をするかどうか確認
   - 工事案内（日程・内容）の配布を依頼する
10. **急がせる営業は避ける**
    - 焦って契約しない
    - 本当に良い会社は検討する時間を与えてくれる
    - 「今日だけの値引き」は要注意

---

## 備考

- 塗料グレード: フッ素＞シリコン＞ウレタン（耐久年数と費用のバランスで選択）
- 相場感の確認は伊能忠敬に依頼すること
